# Chatty App - Real-time Chat Application

A **real-time chat application** built using the **MERN stack** (MongoDB, Express.js, React.js, Node.js) with **Socket.io** for seamless instant messaging.

---

## 🚀 Features

- **Real-time messaging** powered by **Socket.io**
- Secure **user authentication** (Login / Register)
- **Persistent chat history** stored in **MongoDB**
- Responsive and modern UI with **React.js**
- Clean, scalable backend using **Express.js**

---

## 🛠️ Tech Stack

| Technology     | Purpose                     |
|----------------|-----------------------------|
| **React.js**   | Frontend UI & State Management |
| **Node.js**    | Backend Runtime             |
| **Express.js** | RESTful API & Server Logic  |
| **MongoDB**    | NoSQL Database (Mongoose ODM) |
| **Socket.io**  | Real-time Bidirectional Communication |
